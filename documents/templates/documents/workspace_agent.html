⚙️ First-time setup on a new PC (click to expand)
  1. Install Python 3.10+ from python.org — tick "Add Python to PATH"
  2. Extract the ZIP, open the folder
  3. Double-click RunAgent.bat — it auto-installs packages on first run
  4. In the popup: enter this server's URL ({{ server_url }}), login, and choose a folder to watch
  5. Click Launch Agent — done. Optionally place a shortcut of StartAgentBackground.bat in shell:startup to auto-start on login.
